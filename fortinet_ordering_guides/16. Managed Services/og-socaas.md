more proactive cyber defense.

across their environment. These insights help improve security posture by enabling teams to optimize Security Fabric
configurations and proactively prevent incidents.

SOC as a Service™ - Scale your SOC with automation, Agentic AI, and industry-leading threat intelligence Ordering Guide
MSSP / Partner Order Information
SOCaaS offers multi-tenancy options to support partners providing Managed Security Services. SOCaaS native multi-tenancy
feature works well for MSSPs who own, register and manage Fabric devices and licenses. MSSPs can define multiple tenants
and set up separate monitoring for devices and data sources.
Dedicated vs. Shared Fabric Devices
MSSP assigns a dedicated fabric device to a single tenant during onboarding and then monitored exclusively for that tenant.
Fabric devices set up for multi-tenancy using FortiGate VDOMs or FortiClient EMS Sites could be assigned to multiple tenants
and then monitored separately for each tenant.
Multi-tenancy using FortiCloud Organizations
SOCaaS also supports multi-tenancy using FortiCloud Organization feature. This setup works well for MSSPs who manage
multiple FortiCloud accounts. Each account would represent a tenant during the onboarding process. While Fabric devices are
registered in multiple FortiCloud accounts, MSSPs can manage devices across all tenants and maintain visibility on SOCaaS
portal content in a single pane.
