FortiSASE
Extend the corporate perimeter to secure data to/from all endpoints, and enable secure access
to the Internet, private applications, and SaaS applications.
With the rise of hybrid work, combined with application migration to cloud and SaaS, organizations
must now secure employees who access the network and applications from anywhere. This shift
has significantly expanded the attack surface, thereby increasing the complexity of network,
application, and data security.
Companies with existing Fortinet deployments can seamlessly expand their network to include
SASE locations that join natively with their SD-WAN, NGFW or DCFW segments. This enables
SASE adoption without impact to NOC/SOC teams, plus eliminates the need to architect &
maintain complex routing configurations. Zero Trust is included with all FortiSASE deployments.
New customers can seamlessly migrate to FortiSASE by leveraging Fortinet ADS (Advanced
Deployment Services), which simplifies onboarding through guided planning, automated
configuration, and rapid policy migration with minimal disruption to users and operations.
How It Works
Once deployed, all users and device traffic is automatically inspected by FortiSASE (with optional
zero trust enforcement) before allowing access to the Internet, private networks or corporate
SaaS applications.
Deployed SASE points of presence (POPs) seamlessly connect to existing FortiGate NGFW, SD-
WAN or DCFW deployments. And, with FortiOS everywhere, existing NOC/SOC processes can
easily manage FortiSASE locations.

Frequently Asked Questions
How do I get started with FortiSASE?
All new customers should purchase a User-based license to get started. All other SKUs are registered on top of the initial
deployment.
How many locations are included with the User Subscription?
FortiSASE Standard and Advanced user subscriptions include up to 4 locations, selected during activation.
FortiSASE Comprehensive subscriptions of less than 200 users include access to 1-2 locations. Refer to https://links.fortinet.
com/fortisase/dcs-per-license for details.
How many locations can be supported with the Location Add-on license?
Up to 16 additional locations can be purchased for a maximum of 20 total locations.
What locations are supported in Standard, Advanced and Comprehensive?
Refer to: https://links.fortinet.com/fortisase/global-data-centers.
Can I mix Standard, Advanced and Comprehensive together in the same account?
The Region Add-on SKU can be mixed when combined with a FortiSASE Comprehensive subscription. A customer may
purchase either the Fortinet Location or Public Cloud location add-on license, depending on individual requirements.All other
components in the account must use the same type. Multiple accounts can be used for different types.
What FortiGate platforms does the SPA Service connection support?
All platforms are supported, but for SD-WAN deployments the FortiGate-100F and above is strongly recommended. Desktop
platforms may be used for single NGFW connections.
Is the SPA license required for every FortiGate in an SD-WAN deployment?
No, the SPA license is only required for the Hub locations.
If the Hub or single NGFW location is an HA Cluster, is a license needed for each member?
Yes.
I already purchased the FortiClient ZTNA/VPN or EPP/APT options. Can I upgrade them to SASE?
Yes. Refer to the following documentation: https://links.fortinet.com/fortisase/faqs.
How is the Data Transfer calculated?
Tenant level Data Transfer is calculated by adding up entitlement for all purchased contracts. For example, a subscription for
100 users would entitle for 25 TB of Data Transfer globally. Refer to the Service Description for more details.
How many dedicated IPs can I add to a single Security PoP?
Each Fortinet or Public Cloud Security PoP can support up to 5 dedicated egress IPs (DEIPs), 4 of these DEIPs can be used for
source IP anchoring rules.

How many connections can a Branch On-Ramp Location support?
Each Branch On-Ramp Location includes 1 Gbps of shared bandwidth for up to 2000 supported connections. Each account
can have a maximum of 20 Branch On-Ramp locations and a total of 40,000 Branch On-Ramp connections. Bandwidth is
dedicated to the Location and not shared with Remote Users or Edge Devices. Multiple On-Ramp Locations can be provisioned
in the same FortiSASE Region. Each Location has a standalone bandwidth limit.
What devices can connect to a Branch On-Ramp Location?
For a full list of supported device types, refer to: https://links.fortinet.com/fortisase/sd-wan-on-ramp
How many Locations can be supported with the Branch On-Ramp License?
Up to 20 Branch On-Ramp Locations can be purchased for a single account. A minimum of 2 locations is required for
redundancy.
Can FortiSASE be managed by FortiManager?
Yes, FortiManager 7.4.4 and higher can synchronize Security Profiles, Users, Groups and Firewall Objects with FortiSASE.
How does FortiManager license FortiSASE?
FortiManager must be purchased separately and counts FortiSASE as one managed device. No additional FortiSASE license
is required.
Does FortiTrust Identity support user’s accounts on multiple remote Identity Providers and Directories?
You can use FortiTrust Identity as an IdP Proxy with multiple remote IdP and on-prem directories. More details can be found
here.
How can I ensure homogeneous identity verification policy when there are users from multiple remote Identity Providers
and Directories?
FortiTrust Identity, as an IdP proxy, can detect whether MFA was performed at the remote IdP and enforce or bypass
depending on the condition. Further, FortiTrust Identity can be used to apply centralized Adaptive Authentication policies
across federated IdPs.
What is the maximum number of FortiAP that can be connected to FortiSASE?
A maximum of 240 FortiAP can be connected to FortiSASE.
What is the maximum number of FortiExtender or FortiBranchSASE that can be connected to FortiSASE?
A maximum of 1024 FortiExtender and FortiBranchSASE can be connected to one FortiSASE account.
How are user seats counted?
You start consuming a user license when a user registers their first device. They’ll keep consuming that license until either a
FortiSASE admin manually removes them, or until all their registered devices have no telemetry check-ins for more than 45
days, at which point their license will be released. Every user is entitled to register to three different devices, if they register to
a fourth one, an additional license will be consumed.
