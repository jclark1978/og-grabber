The FortiFlex Program
Many enterprise organizations need to meet their IT and security requirements
with greater agility and cost efficiency. Increasingly, organizations expect a cloud-like
consumption experience, including self-service provisioning, elastic scaling, and usage-
based billing.
The FortiFlex program enables organizations to:
• Accelerate deployment with on-demand provisioning
• Reduce procurement complexity and delays
• Eliminate traditional licensing constraints
• Transition to a predictable and scalable OpEx consumption model
FortiFlex provides a unified licensing framework that supports pay-as-you-go and
prepaid consumption models across virtual appliances, security services, and cloud-
delivered services. It extends the flexibility of public cloud marketplaces to the broader
Fortinet ecosystem, including hybrid and multi-cloud environments.
What is FortiFlex Enterprise?
FortiFlex Enterprise is a prepaid, points-based subscription model that enables
organizations to deploy, manage, and scale a wide range of Fortinet security services.
Using FortiFlex Points, customers can:
• Provision services across virtual machines, cloud workloads, SaaS services, and
hardware
• Dynamically allocate capacity based on real-time needs
• Centrally manage entitlements through the FortiFlex Portal.
For virtual environments, customers can create and scale multiple VM entitlements
aligned with workload requirements. For hardware, entitlements can be associated with
registered devices.
Once Flex Points are activated in a FortiCloud account, administrators gain immediate
access to on-demand consumption across the Fortinet Security Fabric, including SaaS,
PaaS, and public cloud integrations.

FortiFlex Ordering Guide
What is FortiFlex MSSP?
FortiFlex MSSP is a postpaid, consumption-based subscription model designed for Managed Security Service Providers
(MSSPs) and Telcos, where usage of deployed services and entitlements is continuously tracked and billed monthly, ensuring
accurate consumption-based charging.
It enables partners to:
• Deliver flexible and scalable security services to end customers
• Pay monthly based on actual usage (measured in FortiFlex Points)
• Align costs directly with customer consumption and service delivery
MSSPs can deploy services across:
• Virtual machines
• Hardware devices
• Cloud and SaaS-based security offerings
This model supports:
• Multi-tenant environments
• Elastic scaling per customer
• Simplified billing and cost alignment with revenue
FortiFlex Product Offerings & Sizing
The FortiFlex program supports a comprehensive portfolio of Fortinet solutions, including:
• Virtual machines (VMs)
• Hardware appliances
• Cloud-native and SaaS security services
Customers can size and estimate consumption using the FortiFlex Calculator, which provides up-to-date:
• Product availability
• Flex Points consumption rates
• Deployment scenarios across environments
For the latest offerings and sizing guidance, refer to the FortiFlex calculator page on the FNDN.

FortiFlex Ordering Guide
FortiPoints Transfer
FortiPoints can be converted into FortiFlex credits and added to an active FortiFlex balance via FortiMarketplace.
Key considerations:
• Transfers are final and non-reversible
• Conversion rates vary based on volume tiers:
• Below 50,000 FortiFlex points:
• 1 FortiFlex = 1.2 FortiPoints
• Transferred points are valid for 3 years from transfer date.
• Between 50,000 and 999,999 FortiFlex points
• 1 FortiFlex = 1.0 FortiPoints
• Transferred points are valid for 3 years from transfer date.
• Above 1,000,000 FortiFlex points:
• 1 FortiFlex = 1.0 FortiPoints
• Transferred points are valid for 5 years from transfer date.
This tiered structure incentivizes larger commitments and enables customers to optimize cost efficiency at scale.
Order Information
• All purchased SKUs must be registered within 365 days of purchase
• MSSP program requires a minimum annual consumption commitment (e.g., 50,000 points)
FortiFlex Prepaid
• If consumption exceeds available balance:
• A 90-day grace period is provided to restore balance
• During this period:
• Existing services continue operating
• New entitlements cannot be created
• After the grace period, services are suspended
FortiFlex Postpaid
• If annual consumption is below the minimum commitment:
• A true-up adjustment is applied
• Continuous service operation depends on meeting usage and billing requirements
