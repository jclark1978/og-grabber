Welcome to the Fortinet Cloud Marketplace Private Offers Ordering Guide. This guide
is designed to help customers understand and navigate the various options available for
deploying Fortinet’s diverse range of cost-effective and value-added cloud marketplace
security solutions.
These exclusive private offerings empower customers to leverage Fortinet’s industry-
leading cloud products with strategic cloud security partners. They are specifically
tailored to each customer’s needs, helping them reduce operating costs through
seamless procurement and unified billing solutions, while enhancing their approach to
security.
This guide outlines:
• Key Capabilities: Cloud Marketplace Private Offers enable customers to access
various Fortinet Cloud and SaaS security solutions, including FortiAppSec Cloud WAF-
as-a-Service, FortiEDR, and FortiCNAPP.
• Supported Cloud Marketplaces: AWS, Azure, GCP, OCI, and AliCloud.
• Benefits: Buyers can benefit from negotiated, off-list pricing and customized solutions,
and the reduction of their monetary commitments to cloud service providers. Sellers
can leverage private offers to streamline procurement, increase engagement, and
accelerate closing large deals.

Fortinet Training and Certification
FCP - Google Cloud Security Administrator Training and Certification
This course covers the different components that make up the Google Cloud infrastructure and explores the security challenges
associated with these environments. Topics include high availability (HA), load balancing, software-defined network (SDN)
connectors, and traffic management in the cloud using Fortinet products.
FCP - AWS Cloud Security Administrator Training and Certification
This course explores the various components that comprise the Amazon Web Services (AWS) infrastructure and examines the
security challenges these environments present. It covers topics such as high availability (HA), load balancing, software-defined
networking (SDN) connectors, and traffic management in the cloud using Fortinet products.
FCP - Azure Cloud Security Administrator Training and Certification
This course delves into the various components of the Microsoft Azure infrastructure and addresses the security challenges
associated with these environments. It covers topics such as high availability (HA), autoscaling, Azure Virtual WAN, software-
defined networking (SDN) connectors, and traffic management in the cloud using Fortinet products.
FCSS - Public Cloud Security Architect Training and Certification
This course focuses on deploying Fortinet solutions in the public cloud using various methods. It covers the use of third-party
automation tools to deploy and secure cloud resources, effective troubleshooting of common connectivity issues in Azure and
AWS, and leveraging FortiCNP to streamline risk management for cloud workloads.
