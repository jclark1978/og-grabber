FortiDLP
FortiDLP is a cloud-native endpoint data loss prevention (DLP), insider risk and
AI security solution, and a core component of the Fortinet AI-Native Security Fabric.
FortiDLP continuously monitors endpoint, corporate cloud drive activity, and user and
AI agent behavior to detect and prevent accidental data loss and data exfiltration.
The solution addresses data security compliance requirements with out-of-the-box
support for data privacy legislation and industry regulations.
FortiDLP offers the following tiers:
• Core: Gain immediate visibility and control over data movement on your endpoints
to guard against data misuse and loss. The Core license includes endpoint data loss
prevention features such as real-time content inspection, SaaS app inventory with
data risk analytics, browser-based AI chatbot prompt block and capture, and egress
controls based on data origin. It is ideal for organizations that want to address
regulatory compliance mandates and educate users on proper handling of sensitive
data and IP.
• Advanced: Building on the Core license, the Advanced license provides agentic AI
activity visibility for endpoint AI agents and extensive user, data, and file activity
event streams across managed endpoints and corporate cloud drives. It adds
machine learning to establish user and agent activity context, MITRE ATT&CK®-
mapped insider threat sequence detection, screenshot evidence captures, and
FortiAI case report generation for analysts and business stakeholders. It is ideal for
organizations seeking full visibility into user and AI agent interactions with sensitive
data and intellectual property, the ability to answer the “who” and “why” behind
data at risk, and the ability to intervene early when risky behavior is observed.
• Managed Advanced: Fortinet experts work as an extension of your security team
to help set up, optimize, and provide ongoing management and monitoring of data
security risks across the organization.
FortiDLP offers a Best Practices Service (BPS) to assist with onboarding. All new
customers are required to use the BPS service for their first year. If a new customer
selects the Managed Service, it fulfills the BPS requirement.
FortiDLP capabilities are also available as part of FortiEndpoint, Fortinet’s unified
endpoint agent and console. See the FortiEndpoint Ordering Guide and the FAQ below
for how the FortiDLP feature set maps to FortiEndpoint tiers.

Frequently Asked Questions
What are Secure Data Flow and Data Lineage?
Secure Data Flow enables DLP policies based on data origin, such as files downloaded from Salesforce while Data Lineage
tracks a file’s journey across the endpoint. An analyst can view data lineage from download to manipulation to exfiltration in the
DLP detection (alert).
Which license best suits customers looking for a comprehensive Endpoint DLP product?
FortiDLP Core offers enterprise Endpoint DLP features, including ready-to-use regulatory compliance policy templates, inline
content, and context-aware DLP controls for browsers, removable storage, Outlook, printers, and applications. It also offers
policy-free visibility into SaaS and Generative AI data egress to identify risks, develop DLP policies, and train employees on best
practices.
Which license best suits customers with a data security program focused on DLP and Insider Risk Management?
FortiDLP Advanced is designed for customers with DLP and Insider Risk programs. It features machine learning-powered
behavioral analysis, MITRE-mapped Insider Threat Sequence Detection, user activity screen capture, and integrated case
management. It also offers enterprise cloud drive visibility, detection and response to ensure seamless data tracking across
managed and unmanaged devices.
Which PoPs (hosting regions) require the FortiDLP Advanced with Premium Hosting license?
Deployment in the Kingdom of Saudi Arabia (KSA) requires the FortiDLP Advanced with Premium Hosting license.
Is BPS mandatory for FortiDLP?
BPS is mandatory for new customers for the first year so that our customer success team and product experts can help guide
customers through deployment and solution configuration. After the first year, BPS is optional. Customers can also opt for the
Managed Service, which includes BPS.
Alongside visibility and detection for managed endpoints, does FortiDLP provide visibility and detection for activity in
enterprise cloud drives?
Yes. FortiDLP Advanced, Advanced with Premium Hosting, and Advanced with Managed Service licenses provide Microsoft
OneDrive/SharePoint, Google Drive (Workspace), and Box cloud drive connectors. These connectors audit, track, and detect
data sharing and download activities across managed and unmanaged devices with access to corporate cloud drive systems.
How is FortiDLP deployed?
FortiDLP is a cloud multi-tenant SaaS solution. The FortiDLP console is SaaS only; there is no on-premises console. FortiDLP
supports a customer-managed Evidence Store on any S3-compatible object storage, in the customer’s private cloud or on
premises. Agents are available for Windows (x64 and ARM64), macOS, and Linux (Ubuntu and RHEL) desktop operating
systems, and for non-persistent VDI and DaaS environments including Citrix Virtual Apps and Desktops and Azure Virtual
Desktop.
Does FortiDLP support integration with SIEM and SOAR products?
FortiDLP provides out-of-the-box support for FortiSOC, FortiSIEM, Splunk, and MS Sentinel SIEMs, as well as FortiSOAR and
third-party SOAR solutions.

In which regions can a FortiDLP tenant be hosted?
FortiDLP tenants are hosted in regional data centers in the United States (Virginia), Canada (Montreal), the European Union
(Belgium), Australia (Melbourne), Singapore, India, Qatar, and the Kingdom of Saudi Arabia. All tenant data, including backups,
remains in the region selected at provisioning. Saudi Arabia requires the FortiDLP Advanced with Premium Hosting license.
Evidence files are written to the customer-managed Evidence Store on S3-compatible object storage, in the customer’s private
cloud or on premises.
Is FortiDLP available as part of FortiEndpoint?
Yes. FortiEndpoint Protect Core, Protect Plus and Protect XDR include DLP Essentials, the FortiDLP Core feature set without the
Incident Management module. Protect Data and Complete include DLP Advanced, which adds insider risk management, SaaS
integration and incident management. Managed Protect Data and Managed Complete add the DLP Managed Service. See the
FortiEndpoint Ordering Guide for SKUs.
How does FortiDLP protect data shared with generative AI tools?
FortiDLP provides a policy-free inventory of browser-based GenAI chatbots and SaaS applications in use, including whether they
are accessed with corporate or personal accounts, in all license tiers. Policies can coach the user, require justification, or block
a prompt or upload that contains sensitive data, and the prompt text can be captured as evidence to the customer’s evidence
store. Visibility into endpoint AI agents and AI services is included in the Advanced license.
