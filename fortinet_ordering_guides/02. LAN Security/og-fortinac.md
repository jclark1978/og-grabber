Ordering Guide
FortiNAC
Welcome to the Fortinet FortiNAC Ordering Guide. This guide is designed to help
customers understand and navigate the various options available for deploying Fortinet’s
network access control solution. FortiNAC enhances the Fortinet Security Fabric
with comprehensive visibility, robust control, and automated response capabilities
for everything that connects to your network. It also enables the implementation of
microsegmentation policies and configuration changes across switches and wireless
products from a wide range of vendors.
This guide outlines:
• Key FortiNAC capabilities, including network discovery, device profiling, authentication
(Captive Portal, RADIUS), user and guest management, BYOD/onboarding, endpoint
compliance, and automated control features like rogue device detection and firewall
segmentation.
• Details on FortiCare offerings, which provide essential support services such as
firmware updates, weekly network device database updates (supporting over
2400 devices), and access to the FortiGuard IoT Service for cloud-based device
identification.
• Information on simplified licensing packages, including PLUS (entry-level with endpoint
visibility, dynamic VLAN steering, advanced NAC, automated provisioning) and PRO (all
PLUS features with enhanced visibility, control, and response).
• Options for perpetual and subscription licenses, available in various endpoint ranges
(e.g., 100, 1000, 10000, 50000 endpoints).
• Details on FortiNAC hardware appliances (e.g., FNC-CA-500F, FNC-CA-600F, FNC-
CA-700F, FNC-M-550F) and virtual appliances, categorized by network port capacity
for SMB, Mid Enterprises, and Large Enterprises.
• Mandatory FortiCare SKUs for endpoint licensing and for activating support for
hardware/VMs.
• Available Professional Services (e.g., FortiNAC Professional Service) and QuickStart
Services for deployment assistance.

Product Offerings
FortiNAC is available with the following FortiCare offerings:
FortiCare Services
As a customer’s business rapidly evolves, advancing its security capabilities is critical as well. Often, the customer
does not have expertise within their organization to deploy, operate, and maintain these new capabilities or
are up against tight deadlines to implement change. Fortinet understands this challenge and helps thousands
of organizations every year tackle this problem with FortiCare Services. Fortinet’s experts provide accelerated
implementation of the customer’s technology, reliable assistance through advanced support, and proactive care
to ensure the customer’s success with Fortinet investment. No matter the size or location of the customer’s
organization, Fortinet is ready to provide the customer with an elevated experience to help them achieve their
business goals with superior security and performance.
FortiCare Support
A FortiCare Support contract entitles the customer not only to receive updates to the FortiNAC firmware, but also
receive the following important feeds:
• Network device database update: FortiNAC supports more than 2400 switching, wireless, or firewall devices on
the market. As new devices release, FortiNAC’s network device database updates to reflect these new models.
The weekly update from the FortiNAC team keeps the customer’s deployment up to date.
• FortiGuard IoT Service: a method that FortiNAC has to identify devices is to use the cloud lookup service that
FortiGuard Labs hosts. A FortiCare Support contract entitles the customer to use that service at no additional
cost, giving them access to a database of millions of devices.
License Package
FortiNAC offer the broad features and deep integration capabilities through two licensing tiers: PLUS and PRO:
• PLUS: powerful and comprehensive features with the entry-level licensing package, provides endpoint visibility and dynamic
VLAN steering, advanced network access controls, and automated provisioning for users, guests, and devices.
• PRO: includes all PLUS features and increases the level, providing the ultimate visibility, control, and response.
With the perpetual and subscription licensing pricing changes, the new FortiNAC-F hardware appliances had their prices revised
due to Fortinet’s new production of these appliances. With a production cost reduction, we can deliver cost savings for our
customers without affecting performance and scalability.

Appliance Migration from CentOS to FortiNAC-F OS
New appliance migration tool released:
• Single Appliance
• FortiNAC Manager Environments
• High Availability
Migration FAQ 1: What is the process for migrating?
• Purchase/acquire the NAC-OS VM (FNC-CAX-VM or Manager FNC-MX-VM).
• On the CentOS VM, if FortiNAC is on 8.x, upgrade to 9.x to one of the following versions: 9.1.10, 9.2.8 or 9.4.4 or v7.2.3
• A tool shipped with v7.2.x to copy customer data from the v9 system into a file, which they need to store in a laptop.
• Customer must log in to FortiCare to transfer their entitlements, including licenses and FortiCare contracts, from the old VM to
the new. They need serial numbers of both old and new VMs, plus other information that FortiCare requires.
• Customer then logs into the new NAC-OS VM, upgrade to 7.2.2, where they can use a tool to read the file generated in step
3 and push the data into the local FortiNAC system. Now the new FortiNAC-OS based VM will have all the license, contracts,
plus the data to operate.
Migration FAQ 2: Does the conversion tool convert Manager and all PODs?
Yes, the conversion tool will cover the CA and Manager, but the migration process needs to be done one by one, starting with
the PODs and then migrating the Manager last.
Migration FAQ 3: Does the migration process cover all exiting deployed FortiNAC configs?
• Does not cover customer with Subscription Licensing.
• Does not cover HW appliances. The migration tool to refresh the FortiNAC-F install in the C-series is under production.
Migration FAQ 4: If we have a customer that is still running the old two appliance solution, FNC-C-VM and FNC-A-VM or
older (FNC-C-1000C and FNC-A-1000C, FNC-C-2000C and FNC-A-2000C), will the conversion tool have the ability to
migrate them from two appliances to one new FNC-CAX-VM? If not, assuming we would sell PS time to do that type of
conversion?
For the old Control or Application appliances, the original migration tool will not cover that migration. A new migration tool has
been created to migrate a separate C appliance and A appliance to a single NAC-OS appliance.
