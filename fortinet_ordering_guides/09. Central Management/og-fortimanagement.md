FortiManagement Cloud
Cloud
Simplified Cloud Network Management and Analytics
FortiManagement Cloud is Fortinet’s unified SaaS platform that simplifies administration, enhances
visibility, and delivers centralized management, security analytics, and operational control for
FortiGate, FortiAP, FortiSwitch and FortiExtender devices with a single unified cloud console.
Built on the FortiCloud platform, it provides a seamless and scalable cloud-based experience
that accelerates deployment, streamlines operations, and helps organizations maintain a strong
security posture through a single, intuitive interface. Whether managing a few devices or a globally
distributed deployment, FortiManagement Cloud enables organizations and service providers to
efficiently operate, monitor, and secure their networks from anywhere.
Key Benefits of Unified Management and Analytics Solution
• Reduce Infrastructure Costs
Eliminate the need for dedicated on-premises management infrastructure, lowering upfront
capital expenditures while reducing operational overhead and IT resource requirements.
• Enterprise-Class Reliability and Security
Benefit from a highly available, secure, and redundant cloud architecture backed by 24x7
service operations, helping minimize disruptions and support business continuity.
• Scale on Demand
Adopt a flexible pay-as-you-grow model that allows organizations to start small and seamlessly
expand as network size, users, and operational requirements grow.
• Unified Visibility, Control and Analytics
Gain centralized management, monitoring, analytics, reporting, and security insights across
devices, sites, and services through an all-in-one cloud-based platform.
• Faster Deployment and Simplified Operations
Accelerate onboarding, policy deployment, and ongoing administration with streamlined
workflows, centralized configuration management, and automated operational tasks.
• Secure Multitenancy for Service Providers
Support multiple customers or business units through complete tenant isolation, enabling
managed service providers and large enterprises to operate with confidence and security.
• Anywhere Access
Manage your network and security infrastructure from any location through a modern web-
based interface, without the complexity of maintaining management servers.

FortiManagement Cloud Ordering Guide
Fortinet Cloud-based Network Management Options
FortiManagement Cloud
FortiManagement Cloud is a Software-as-a-Service (SaaS)-based solution ideal for SMBs and Managed Service Providers
(MSPs) that prioritize simplicity and easy of use. It offers centralized network management, monitoring, and analytics for
FortiGate NGFWs, FortiAP wireless access points, FortiSwitch Ethernet switches and FortiExtender cellular gateways from an
intuitive, streamlined cloud experience.
FortiManager Cloud
FortiManager Cloud is a Platform-as-a-Service (PaaS)-based solution designed for distributed enterprises with more
complex network environments that require advanced management, orchestration, and control of the Fortinet Security
Fabric. FortiManager provides extensive capabilities and supports a broad ecosystem of integrations, enabling enterprises to
integrate network management into their existing operations.
For more detail, visit FortiManager Ordering Guide. (https://www.fortinet.com/content/dam/fortinet/assets/data-sheets/og-
fortimanager.pdf)
FortiManagement Cloud Offerings
FortiManagement Cloud provides centralized control and visibility for:
• FortiGate and FortiGate managed FortiAP, FortiSwitch and FortiExtender devices.
• FortiAP, FortiSwitch and FortiExtender devices directly managed via cloud (without FortiGate)
Subscription Tiers
FortiManagement Cloud offers per-device subscriptions. Its Standard subscription tier provides comprehensive cloud
management and analytics capabilities to simplify network operations. A Basic tier with limited capabilities is available for trial
purpose, subject to availability and eligibility requirements.
For more information about subscription types, see the FortiManagement Cloud Admin Guide in Fortinet Document Library.
(https://docs.fortinet.com/document/fortimanagement-cloud)

FortiManagement Cloud Ordering Guide
Frequently Asked Questions
Is FortiManagement Cloud a new product?
FortiManagement Cloud consolidated FortiGate Cloud and FortiEdge Cloud into an integrated cloud management and
analytics solution for FortiGate, FortiAP, FortiSwitch and FortiExtender devices. Enhanced with new features and capabilities,
FortiManagement Cloud delivers a more intuitive user experience and streamlined management for FortiGate and FortiGate-
managed devices as well as stand-alone deployments—all from one unified service.
Does FortiManagement Cloud have different subscription tiers?
FortiManagement Cloud Standard subscription is designed for organizations looking for an intuitive cloud experience with
comprehensive management and analytics capabilities to simplify your operations. A Basic tier is also provided subject to
availability and eligibility criteria for trial purposes. For more information, please see subscription type section in the admin guide
available at https://docs.fortinet.com/document/fortimanagement-cloud.
How do I upgrade from a FortiManagement Cloud Basic tier to a Standard tier?
Purchase and register the FortiManagement Cloud Standard subscription to unlock the full set of features and benefits.
Is the FortiManagement Cloud subscription per device?
Yes. One subscription is required for each FortiGate, FortiWiFi, FortiAP, FortiSwitch, or FortiExtender being managed in
FortiManagement Cloud. However, if FortiAP, FortiSwitch, FortiExtender are connected and managed via a FortiGate firewall,
subscription is needed only for FortiGate. FortiAP, FortiSwitch and FortiExtender directly managed in cloud without FortiGate will
require per device subscription. Devices should have FortiCare Premium Support on all devices managed by FortiManagement
Cloud for support coverage.
How does FortiManagement Cloud offer zero-touch provisioning (ZTP)?
Yes. FortiManagement Cloud includes zero-touch provisioning capabilities for all supported devices, allowing them to be
imported and provisioned to cloud with FortiCloud key or bulk key (FortiDeploy single use SKU).
Is FortiDeploy a different subscription?
Yes, FortiDeploy is used for bulk deployment of FortiGates into FortiManagement Cloud. This can be ordered one per PO.
Alternatively, using the Pending Registration feature for bulk registrations is recommended for seamless and automated bulk
registration process.
Do FortiManagement Cloud subscriptions support FortiSwitch, FortiAP, and FortiExtender devices?
FortiManagement Cloud supports FortiAP, FortiSwitch, and FortiExtender devices in two different deployment modes –
connected and managed via FortiGate as the controller or directly managemed from FortiManagement Cloud without a
FortiGate.
Is FortiCare Support included with FortiManagement Cloud subscriptions?
For FortiGate devices, FortiCare Premium Support for the hardware is not included in the FortiManagement Cloud subscription.
However, FortiCare Premium Support is included with the purchase of a FortiGuard services bundle, including Enterprise
Protection, Unified Threat Protection (UTP), or Advanced Threat Protection (ATP).
For FortiAP, FortiSwitch and FortiExtender devices, FortiCare Premium is included in the FortiManagement Cloud subscription as
long as the product is being managed by FortiManagement Cloud.
Do we need separate FortiManagement Cloud subscriptions to manage FortiSwitch, FortiAP and FortiExtender devices
connected to a FortiGate?
When FortiAP, FortiSwitch, and/or FortiExtender devices are downstream connected to a FortiGate, no separate
FortiManagement Cloud license is required to manage these devices.
Does FortiManagement Cloud support my previous FortiGate Cloud and FortiEdge Cloud SKU and how do we transition to
FortiManagement Cloud?
Any existing FortiGate Cloud and FortiEdge Cloud SKUs are compatible with FortiManagement Cloud and continue to work untill
the expiration dates. Thereafter, customers can switch to the new FortiManagement Cloud SKUs.

How do I add/enable UTP (Unified Threat Protection) license to FortiAP
After registering a FortiManagement Cloud subscription for FortiAP, register UTP (Unified Threat Protection) at https://fortinet.
com/register. During the registration select the FortiAP to which the UTP subscription license will be applied. Once this
subscription is registered, UTP settings available within the SSID configuration options will be pushed to the devices with this
subscription.
What happens when the FortiManagement Cloud subscription is expiring?
We recommend renewing the subscription before expiration. To accommodate any unexpected impact and avoid loss of service
continuity, upon the expiration of a valid subscription, a generous grace period is provided to facilitate a seamless renewal
process. See FortiManagement Cloud admin guide for grace period and platform behavior available at https://docs.fortinet.com/
document/fortimanagement-cloud.
We previously used SKU (FCLE-10-FCLDO-161-02-12) for sub-accounts-based multitenancy. What is the recommendation
for replacement?
This legacy sub-accounts-based multitenancy SKU has reached its end-of-life and is replaced with FortiCloud Organizations or
Asset Folder based tenant management. With FortiCloud Organizations, by default, all accounts can use multitenancy for up to
10 accounts. For unlimited accounts, registering an FNDN basic account with the same email ID is required.
We use legacy multitenancy right now; will Fortinet stop supporting it?
Any customer with an existing, valid -161 license will be able to use it until the end of the license term. They will not be able to
renew it at the end of the term and will need to register FNDN basic account to use Organizations Multitenancy or migrate to
Asset Folder based multitenancy supported by FortiManagement Cloud.
How can I migrate my legacy multitenant structures to Organizations multitenancy?
Work with your Fortinet account team to help you with the migration.
We have FC-10-xxxxx-1125-02-12 on devices for SD-WAN Overlay-as-a-Service, but it is not available for order. What is the
recommended replacement?
We have introduced new SD-WAN bundles (e.g. FC-10-xxxxx-1337-02-DD and FC-10-xxxxx-1339-02-DD) for hardware devices
which deliver comprehensive SD-WAN capabilities and include both FortiManagement Cloud Standard subscription and SD-WAN
Overlay-as-a-Service.
How do I order SD-WAN Overlay-as-a-Service for FortiGate VM?
For FortiGate VM deployment, Fortinet continues offering services on an à la carte basis. To leverage SD-WAN Overlay-as-a-
Service, we recommend customers purchase FC1-10-xxxxx-1125-02-DD that includes this functionality.
Does FortiManagement Cloud support multiple regions and separate subscriptions needed for different regions?
Multiple regions are supported. Please see the FortiManagement Cloud Administration Guide at https://docs.fortinet.com/
document/fortimanagement-cloud for latest supported regions. FortiManagement Cloud subscriptions are per device and can
be used across any region.
