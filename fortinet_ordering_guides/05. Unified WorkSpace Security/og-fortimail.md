such as phishing, spear phishing, spam, targeted attacks, ransomware, impersonation,
and Business Email Compromise (BEC) attacks.

deployment, Virtual Machines for private or public cloud settings, and FortiMail Cloud
(Hosted), which is managed by Fortinet in highly available data centers.
• Product Offerings: Details on FortiMail Cloud (Hosted) options, including Cloud
GW Premium w/ API Connector, Cloud GW Premium, and Cloud GW, outlining their
respective security services.
• Security Services: Information on included FortiGuard services such as AntiVirus,
AntiSpam, Virus Outbreak Prevention Service, FortiMail Cloud Sandbox, and FortiGuard
Image Analysis Service.
• Additional Services: Covers add-on services like 24x7 Support and Cloud Email API
Integration for platforms like Microsoft and Google.
